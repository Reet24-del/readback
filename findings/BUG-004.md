# BUG-004 (needs ear check): letter runs in codes are pronounced as words

| | |
|---|---|
| **Status** | **Unconfirmed.** Here the transcription may be at fault as much as the TTS, so listen before reporting. |
| **Severity** | High: an IFSC or PAN read as a word can't be written down |
| **Engine / voice** | Voice Agent API TTS via `greeting`, voice `anna` |
| **Reproducibility** | 6 of 17 alphanumeric codes |

## Evidence (verbatim transcription)
| Written | Heard |
|---|---|
| IFSC `WYXK0992832` | "**Wix** zero nine nine two eight three two" |
| PAN `IYPPV5695G` | "**Apu** five six nine five G" |
| IFSC `JQOM0751618` | "**COM** zero seven five one six one eight", and the word "IFSC" itself as "AFSC" |
| IFSC `YVVS0760371` | "YVV zero seven six…" (S dropped?) |
| IFSC `TZAF0855939` | "ZAF zero eight five…" (T dropped?) |
| GSTIN `27ABCDE1234F1Z5` | "twenty seven ABCD one two three four F one Z five" (E dropped?) |

Pure-letter runs that look pronounceable ("WYXK" → "Wix") seem to be read as words rather than spelled out. When a code is spelled correctly, the transcription usually writes the letters as one capitalised token ("ABCD"), so dropped letters may be a transcription artefact. **That's why this one needs your ears.**
